rectovspdf.js

The same PDF, server and window size. One viewer at a time, from a cold start.

Choose a document, or drop one here.

Run opens the file, scrolls to page 50 in 2.5 s, zooms to 300% and finds a word, on the left and then on the right. Each side loads in a new frame from unique URLs, so nothing is cached. Times start when the frame is created and include downloading the viewer.

pdf.js runs as its components example sets it up: a worker, range requests and streaming on, its default rendering. Its zoom is set to recto's fit-width scale, so both draw the same pixels. Code is served brotli-compressed; the network presets are Chrome DevTools', applied by the server to one shared link. Memory is the browser's own measure of each side's frame and workers (Chromium only); canvas is the pixels each holds.
